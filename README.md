# Portfolio — GitHub Pages

Personal portfolio site hosted on [GitHub Pages](https://akifyanbak.github.io).

## Structure

- `index.html` — main page
- `styles.css` — styling (dark/light theme)
- `script.js` — theme toggle
- `assets/` — CV files and favicon

## Custom domain (optional)

To use `akif.ie`, add a `CNAME` file with your domain and configure DNS at your registrar:

```
A     @    185.199.108.153
A     @    185.199.109.153
A     @    185.199.110.153
A     @    185.199.111.153
CNAME www  akifyanbak.github.io
```

Then enable the custom domain in **Settings → Pages** on GitHub.
